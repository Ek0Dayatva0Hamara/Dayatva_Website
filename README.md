# Dayatva - A Social Initiative

## Project Structure

The project is organized into several folders, each serving a specific purpose:

- **src/assets**: Contains all the static assets used in the project, such as images, icons, and other media files.
- **src/auth**: Contains all the authentication-related code and configurations, including modules, services, and utilities for user authentication, authorization, and session management.
- **src/components**: Contains all the reusable components used in the project, which are the building blocks of the user interface.
- **src/constants**: Contains all the constant values used in the project, including configuration settings and other static data.
- **src/pages**: Contains all the page components used in the project, each representing a distinct view or route in the application.
- **src/react-redux**: Contains all the code related to integrating React with Redux for state management, including actions, reducers, and store configurations.
- **src/react-redux/slices**: Contains all the Redux slices used in the project, each representing a portion of the Redux state with corresponding actions and reducers.

## Getting Started

To get started with this project, follow these steps:

1. **Install Dependencies**: Run `npm install` to install all the necessary dependencies.
2. **Start Development Server**: Run `npm run dev` to start the Vite development server with HMR.
3. **Build for Production**: Run `npm run build` to build the project for production.
4. **Preview Production Build**: Run `npm run serve` to preview the production build locally.
